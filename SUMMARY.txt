      → Go to analytics.google.com
      → Create property + web stream
      → Copy Measurement ID (format: G-XXXXXXXXXX)
      → Add to .env.local: PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
      → Tracking starts automatically
      
      Files: src/lib/ga.ts, src/layouts/BaseLayout.astro

   B. Google Sheets Integration:
   
      What was done:
      • Created REST API endpoint: POST /api/contact
      • Created Google Apps Script for webhook integration
      • Email validation and required field checking
      • Automatic row appending to Google Sheet
      • Comprehensive error handling
      
      How to set up:
      → Create Google Sheet at sheets.google.com
      → Deploy scripts/google-apps-script.gs as Google Apps Script Web App
      → Copy deployment URL
      → Add to .env.local: GOOGLE_SHEETS_WEBHOOK=<copied-url>
      → Test: submit form, verify data in sheet
      
      Data flow:
      User Form → POST /api/contact → Google Apps Script → Google Sheet
      
      Files: 
        • src/pages/api/contact.ts (REST endpoint)
        • scripts/google-apps-script.gs (Webhook handler)
